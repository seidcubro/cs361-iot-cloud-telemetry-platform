\# M4 Prototype Evidence



This directory contains screenshots demonstrating the local prototype

implemented for the Preliminary Design Review (M4).



Evidence includes:

\- Local services running via Docker Compose

\- Successful POST /v1/telemetry returning 202 Accepted

\- Successful GET /telemetry/latest returning 200 OK

\- Service health endpoint responses



AWS services are mocked locally for M4. Cloud deployment occurs in later milestones.
